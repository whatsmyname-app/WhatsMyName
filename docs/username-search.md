# Free Username Search Tool

A **username search** checks whether a public profile using a chosen handle appears on multiple websites. It is useful for checking your own accounts, researching a brand handle, and finding public profile leads.

## How to search

1. Open [WhatsMyName Apps](https://whatsmynameapps.us/).
2. Enter a username without the @ symbol unless the interface instructs otherwise.
3. Start the search and review the reported statuses.
4. Open relevant public profile links to confirm the result yourself.
5. Export results if you need a record of your research.

A site may block automated checks or change its page structure. A missing or uncertain result does not necessarily mean the username is available.

For a single-platform check, explore the [supported sites directory](https://whatsmynameapps.us/sites/).
