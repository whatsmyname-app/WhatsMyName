# WhatsMyName Apps Documentation

Welcome to **WhatsMyName Apps**, a free browser-based username search and OSINT research tool.

Search public username matches across thousands of websites and social networks at [whatsmynameapps.us](https://whatsmynameapps.us/). You can also use the [Android app](https://play.google.com/store/apps/details?id=whatsmyname.app.us).

## Start here

- [Username search](username-search.md): understand how a cross-site username search works.
- [Reverse username lookup](reverse-username-lookup.md): explore where a public handle appears.
- [OSINT username search](osint-username-search.md): follow a repeatable research workflow.
- [Digital footprint checker](digital-footprint-checker.md): review your own publicly discoverable accounts.
- [Instagram username checker](instagram-username-checker.md): check a platform-specific handle.
- [Android app](android-app.md): use WhatsMyName Apps on Android.

> A username match is a lead, not proof that two accounts belong to the same person. Use public information responsibly.
