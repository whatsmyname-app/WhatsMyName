# Instagram Username Checker

An **Instagram username checker** can help you investigate whether a particular handle appears to be in use.

## How to check

1. Visit the [Instagram username checker](https://whatsmynameapps.us/check/instagram-username/).
2. Enter the handle you want to check.
3. Review the result and verify it on Instagram itself.

Automated checks are not authoritative availability guarantees. A username may be unavailable even if no public profile can be opened, and Instagram's rules can change.

For a broader search, use the [free username search tool](username-search.md).
