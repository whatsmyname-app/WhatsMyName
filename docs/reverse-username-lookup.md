# Reverse Username Lookup

A **reverse username lookup** starts with a known handle and searches for public profiles using the same string on other platforms.

## Responsible workflow

1. Search the handle using the [reverse username lookup tool](https://whatsmynameapps.us/reverse-username-lookup/).
2. Review public matches and open the relevant source pages.
3. Compare context such as profile descriptions only when it is publicly available.
4. Record which results are confirmed, uncertain, or unrelated.

The same username can be used by different people. Never assume matching handles establish identity or ownership.

See also: [OSINT username search](osint-username-search.md).
