# OSINT Username Search Guide

**Open-source intelligence (OSINT)** uses lawfully accessible public information to answer a defined research question. Username enumeration can help identify public profile leads.

## Investigation checklist

1. Define a legitimate purpose and the username you are checking.
2. Run an [OSINT username search](https://whatsmynameapps.us/osint-username-search/).
3. Review matches, non-matches, and blocked or unknown statuses separately.
4. Verify important findings directly on the original websites.
5. Keep source URLs and a date for each observation.
6. Distinguish verified facts from hypotheses in your notes.

## Limits

Automated profile checks can produce false positives and false negatives. Similar handles, abandoned accounts, impersonation, and blocked requests can all affect interpretation. Do not use the results to harass, impersonate, or expose private individuals.
